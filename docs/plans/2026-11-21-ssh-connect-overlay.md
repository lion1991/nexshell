# SSH 连接过渡层

## 背景

SSH 连接中，终端里只有几行静态文字（「⟐ NexShell SSH / 地址 / ◌ 正在…」）。这些字是 runtime 直接写进 grid 的，转圈符号其实不会转。Matt 觉得「不够炫酷」。

## Matt 拍板（2026-11-21）

- 采用原生动画层：连接中在终端上盖一层原生 UI，连上后淡出，露出 shell。
- 先只做 SSH（含直连），满意了再推到 Telnet / 串口。
- 否决：继续在终端里画字符动画（盲文 spinner + 阶段清单）。这种做法换不了字体，也画不了图形，效果有限。

## 做法

- **数据**：`nexshell::ssh_connect_progress`。runtime 状态里加 `connect_progress`（当前阶段、目标地址、开始时间），写进快照。
  - 阶段：TCP 连接 → 身份验证 → 打开终端。
  - `spawn_remote_ssh` 创建 runtime 时就置为 TCP 阶段，第一帧就盖上过渡层，不会先闪一下空终端。
- **交还终端**：遇到需要用户在终端里输入的情况（密码提示、主机密钥变更确认），或者连接失败（`mark_disconnected`），runtime 撤掉过渡层，往 grid 写回当前阶段的那段旧文字横幅。
  - 写回横幅后，密码提示照旧接在横幅下面；失败时也能看到连的是谁、卡在哪一步。
  - 交还之后的阶段照旧写文字横幅，过渡层不再出现。
- **连上**：`finish_connect_overlay` 撤掉过渡层，不写横幅，清屏交给 shell。
- **UI**：`root_view/connect_overlay_section.rs` 在单窗格和分屏两条渲染路径上，给终端叠一层过渡层，背景透明，保留终端底纹。过渡层包在 `nexshell::click_through::ClickThrough` 里，只画不挡，点击和滚轮照样交给下面的终端。内容从上到下：
  - `nexshell::connect_spinner`：雷达式扩散波纹 + 旋转呼吸弧，走 GPU Ring 原语；中心是主机的系统图标。
  - 主机名、地址（隐私模式下打码）。
  - 三个阶段：完成的打勾，当前的高亮，未开始的变暗。
  - 进度条和计时。每完成一个阶段填满 1/3；当前阶段按停留时间渐近填到这一段的 90%，不会自己走满。
  - 切阶段不能跳（Matt 2026-11-21 反馈「太突兀」后补）：
    - 进度条显示值按指数平滑追目标，约 0.4 s 滑到新位置，只增不减。
    - 阶段符号放在固定宽度的槽里，新旧符号和文字颜色在 320 ms 内交叉淡变。
    - 字重全程不变，免得加粗改变文字宽度，带着居中的整行左右挪。
- **动画**：`connect_overlay_helpers.rs` 按会话 id 记淡入（150 ms）和淡出（220 ms）。快照里的进度消失时，画面冻结在最后一帧，然后淡出。
  - 计入 `any_ui_anim_active`，只有最近 300 ms 内画过的过渡层才驱动 tick。标签切走后 tick 自己停，超过 1 s 没画过的状态会被清掉。

## 验证

- 单测覆盖：阶段推进与计时、进度比例、淡入淡出状态机、过期清理，以及 runtime 交还终端时写回横幅、连上时不写横幅。
- 实机看：连接成功、密码提示、密钥变更确认、连接超时、连接中切标签再切回来、分屏。
