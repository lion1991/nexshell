# 0023 左栏改常驻主机列表，主机概览移到右侧面板区

Status: accepted（2026-11-21，Matt 拍板「听 Fable 的」）；部分取代 ADR 0019

## 背景

在终端里想打开另一台已保存的主机，只能先回主页再点卡片。Matt 有几十台主机，主要用鼠标找、用鼠标点。SSH 标签的左栏被主机概览占着，要放主机列表，就得先把概览挪走。

## 决策

- **右侧**：概览面板放在右侧最外沿，和文件面板并排，宽度固定 248。Git 面板只在本地标签出现，概览只在来源是已保存 SSH 主机的标签出现，两者不会同时出现。所以 SSH 标签的布局是「终端｜文件｜概览」，本地标签是「终端｜文件｜Git」。
  - 开合动画沿用 Git 面板那套：槽位不动，只平移面板内容；文件面板已开时被概览推着锁步移动。切标签时面板直接出现，不播动画。
  - 标题栏的概览按钮（activity 图标）排在 Git 按钮后面，两个按钮互斥收展。开关状态全局持久化（`overview_panel_open`），没存过这个值时沿用旧的 `sidebar_open`。
  - 0019 的两条原则保留：一是显示判断有单一来源，按钮显隐、面板渲染、采集三处都按 `sidebar_helpers::overview_panel_source` 判断；二是采集只跟着显示中的面板跑。
- **左侧**：常驻主机列表，宽 220，和主页分组导航同宽，开关用左上角的侧栏按钮。
  - 本地、SSH、Telnet、串口、Git Diff、内置编辑器、进程 / 网络 / 系统详情页上都显示，切标签时左栏位置不变。
  - RDP 标签第一版不显示：远端分辨率按整窗宽度算（`rdp_section.rs` 的 `rdp_content_area`），每开关一次侧栏，远端就要重设一次分辨率。主页仍显示分组导航，设置页不显示。
  - 顶部是搜索框，下面按分组折叠，分组和主机顺序沿用主页，折叠状态持久化。不设「最近访问」区。
  - 每行显示协议图标、主机名和「已打开」圆点（连着是绿色，断开是红色），当前标签对应的主机高亮。地址放在悬停提示里，隐私模式下打码。不显示在线状态，因为那要后台连所有主机。
  - **单击即连**。主机已经开着就跳到那个标签；想再开一个，用行尾悬停出现的「+」或右键「新开连接」。
  - 宽度固定，不能拖。

## 否决 / 搁置（不再重复提）

- ⌘O 快速连接搜索弹窗、「+」下拉菜单里放最近访问：几十台主机时最近访问不够用，Matt 又主要靠鼠标，所以改走常驻侧栏。
- 概览和文件面板合并成一块、靠切换显示：会失去同时看概览和文件的能力，改动也大。先并排，用一段时间再说。
- 窗口窄时自动收起概览：第一版不做。代价是 1280 宽的窗口三块全开时，终端约 65 列。
- 双击才连接：主页的「最近访问」本来就是单击即连，保持一致。

## 影响

- 第 1 步（概览右移）删掉了 `sidebar_push.rs` 和终端页左栏的推入逻辑，`SidebarContent` 只剩 `None / HostLibraryNav`。第 2 步做主机列表时从 git 历史取回 `SidebarPush`。
- 交付分三步，见 `docs/plans/2026-11-21-host-list-sidebar.md`。
